# Changelog

Notable changes to this project are recorded in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). There are no
released versions yet.

## [Unreleased]

### Changed

- The whole project is now in English, its only language: module names, identifiers, comments,
  printed output, scripts, the explanatory page and the documentation. The structure and what each
  example shows are unchanged. The Spanish version is in the git history at commit `4d808dd`.
  - Renamed: `Capacidades` → `Capabilities`, `Efectos` → `Effects`, `A_SoloTipos` →
    `A_TypesOnly`, `D_FilasDeEfectos` → `D_EffectRows`, `debe-fallar/` → `must-fail/`,
    `compilar.sh` → `build.sh`, `salidas/` → `outputs/`, CI workflow `compilar.yml` →
    `build.yml`.
  - The explanatory page moved to `site/` (`template.html`, `build.py`, `index.html`). It is now a
    standalone HTML page with no scripts or external dependencies (the generator highlights the
    Haskell code), and it is published with GitHub Pages by `.github/workflows/pages.yml`.
  - `README.en.md` was removed: `README.md` is the only README.
- The code license changed from MIT to BSD 3-Clause. The text stays under CC BY-SA 4.0.
- `build.sh` chooses the GHC version with `GHC=ghc-X.Y.Z`, builds in one directory per version,
  only adds GHCup to the `PATH` when there is no `ghc` at hand, and also counts an example that does
  not run as a failure.

### Added

- Capability examples in Haskell in four styles: types only, tagless final, transformers
  (`transformers` and mtl style) and a hand-made effect system with rows.
- Examples in `must-fail/` that GHC has to reject.
- `build.sh`: builds and runs the examples, checks that the ones in `must-fail/` do not compile and
  saves everything that is shown to `outputs/`, including GHC's error messages.
- Explanatory page comparing the four styles, generated by `site/build.py` from a template and the
  fragments of `src/`, `must-fail/` and `outputs/`. It links to the repository.
- Licenses for the code and for the text (CC BY-SA 4.0).
- CI with GHC 9.6.7, 9.8.4, 9.10.3, 9.12.2 (reference) and 9.14.1 (experimental), comparing the
  outputs and the page with the ones in the repository.
- The note on how GHC 9.14 shows B's inferred types.
- `CONTRIBUTING.md` and this changelog.

### Fixed

- `outputs/A_TypesOnly.txt` changed from one machine to another (it counts the environment
  variables): the examples now run with a fixed environment.
